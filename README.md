# xiaomi_qianbao_VIP

面向 **青龙面板（QingLong）** 的小米钱包每日任务脚本。

本项目基于 [`kai648846760/xiaomiwallet`](https://github.com/kai648846760/xiaomiwallet) 的核心扫码登录与小米钱包任务逻辑进行青龙适配，去除 Flet/GUI 和多平台打包代码，增加：

- 青龙订阅拉库
- 青龙定时任务
- 一键扫码登录
- 登录凭证持久化保存
- 多账号管理
- 每日自动执行
- 青龙内置通知

> **建议仅在自己的本地青龙环境中使用。** 自动化操作可能触发小米账号风控。项目仅用于个人学习、技术研究和个人账号自动化，不保证接口长期有效。

---

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 青龙订阅 | 在“订阅管理”中直接拉取本仓库 |
| 扫码登录 | 在青龙任务日志中显示二维码，手机扫码后自动保存登录凭证 |
| 免重复扫码 | 登录成功后保存 `userId`、`passToken`、`securityToken`，正常情况下无需每天扫码 |
| 每日自动任务 | 默认每天 `08:37` 自动执行小米钱包任务 |
| 多账号 | 支持保存并依次执行多个小米账号 |
| 持久化配置 | 凭证默认保存在 `/ql/data/config/xiaomi_qianbao_VIP/`，更新仓库不会覆盖 |
| 青龙通知 | 使用青龙提供的 `QLAPI.notify`，复用青龙已有通知配置 |
| 自动依赖 | 首次运行缺少 `requests` / `qrcode` 时会尝试自动安装 |

# 二、推荐安装方式：青龙订阅管理直接拉取

这是最推荐的使用方式。

以后仓库更新时，青龙也可以自动重新拉取代码。

## 1. 打开订阅管理

进入青龙面板：

```text
青龙面板
  ↓
订阅管理
  ↓
新建订阅
```

## 2. 填写仓库信息

仓库地址：

```text
https://github.com/ZzzHe2333/xiaomi_qianbao_VIP.git
```

建议填写：

| 项目 | 内容 |
| --- | --- |
| 名称 | 小米钱包 VIP |
| 类型 | 公开仓库 |
| 链接 | `https://github.com/ZzzHe2333/xiaomi_qianbao_VIP.git` |
| 分支 | `main` |
| 定时类型 | `crontab` |
| 定时规则 | `15 4 * * *` |
| 白名单 | 留空 |
| 黑名单 | 留空 |

这里的：

```cron
15 4 * * *
```

表示每天凌晨 `04:15` 检查并更新一次仓库。

这个时间只是 **更新代码的时间**，不是小米钱包签到时间。

## 3. 保存并运行订阅

创建完成后：

```text
订阅管理
  ↓
小米钱包 VIP
  ↓
运行
```

第一次建议手动运行一次订阅。

拉取成功后，仓库代码会进入青龙的仓库目录。

# 三、确认青龙任务是否自动生成

本仓库中的 Python 文件已经写入青龙可识别的任务信息。

正常情况下会看到两个任务。

## 小米钱包每日任务

```text
任务名称：小米钱包每日任务
Cron：37 8 * * *
```

即：

```text
每天 08:37 自动运行
```

## 小米钱包扫码登录

```text
任务名称：小米钱包扫码登录
Cron：0 0 31 2 *
```

这里故意设置为不存在的：

```text
2 月 31 日
```

因此这个任务正常情况下 **不会自己运行**。

它只用于：

```text
第一次登录
或
登录凭证失效后重新登录
```

需要登录时，在青龙面板中手动点击“运行”即可。

# 四、第一次使用：扫码登录

这是安装完成后最重要的一步。

## 1. 找到扫码登录任务

进入：

```text
青龙面板
  ↓
定时任务
  ↓
小米钱包扫码登录
```

点击：

```text
运行
```

然后打开：

```text
日志
```

## 2. 查看二维码

运行后日志会显示类似：

```text
======= 小米钱包扫码登录 =======
账号别名: xiaomi_1
凭证保存位置: /ql/data/config/xiaomi_qianbao_VIP/xiaomiconfig.json

请使用小米手机/小米账号支持的扫码入口扫描下方二维码：

████████████████████████
██    ██  ██      ██  ██
██  ████      ████    ██
......
```

直接用手机扫描日志中的二维码。

如果青龙网页中的二维码因为字体、缩放或日志排版无法识别，二维码下面还会输出一个登录链接：

```text
如果二维码在日志中无法识别，可复制下面的登录链接到浏览器打开：
https://account.xiaomi.com/......
```

可以复制这个链接到浏览器打开，再扫码。

## 3. 手机确认登录

扫描后，日志会依次显示：

```text
等待扫码
↓
已扫码，请在手机确认
↓
登录成功
```

成功后会看到：

```text
✅ 登录成功，长效凭证已写入青龙持久化配置目录。
小米 User ID: xxxxxxxx
passToken/securityToken 不会输出到日志。
```

此时账号已经保存完成。

# 五、账号 Cookie / Token 保存在哪里？

登录成功后，会保存以下信息：

```text
userId
passToken
securityToken
账号别名
更新时间
```

默认文件位置：

```text
/ql/data/config/xiaomi_qianbao_VIP/xiaomiconfig.json
```

目录结构大致如下：

```text
/ql/data/
├── config/
│   └── xiaomi_qianbao_VIP/
│       └── xiaomiconfig.json     ← 小米账号凭证
│
└── repo/
    └── ...xiaomi_qianbao_VIP/    ← 青龙拉取的仓库代码
```

账号凭证和仓库代码分开保存。

因此：

```text
重新运行订阅
更新 GitHub 仓库
重新拉取代码
```

通常都不会覆盖已经保存的账号。

## 安全提醒

`xiaomiconfig.json` 中的：

```text
passToken
securityToken
```

属于敏感登录凭证。

**不要：**

- 上传到 GitHub
- 发到群里
- 截图公开
- 提交 Issue 时粘贴完整配置
- 发给不可信的人

脚本本身不会在正常日志中打印完整 Token。

# 七、每天自动执行

每日任务默认 Cron：

```cron
37 8 * * *
```

表示：

```text
每天上午 08:37
```

自动执行。

正常情况下流程是：

```text
青龙定时启动
      ↓
读取本地保存的 passToken + userId
      ↓
向小米账号服务换取临时 Session Cookie
      ↓
进入小米钱包活动接口
      ↓
获取任务
      ↓
完成任务
      ↓
领取奖励
      ↓
查询当前奖励
      ↓
青龙通知
```

所以正常情况下：

> **只需要第一次扫码，后面每天自动执行。**

不需要每天重新扫码。

# 八、修改每天执行时间

如果不想每天 `08:37` 执行，可以直接在青龙面板修改。

例如每天上午 `09:26`：

```cron
26 9 * * *
```

每天中午 `12:18`：

```cron
18 12 * * *
```

每天晚上 `20:43`：

```cron
43 20 * * *
```

建议避免大量账号都使用非常整齐的整点，例如：

```cron
0 8 * * *
```

可以自行设置成普通的非整点时间。

# 九、青龙通知怎么使用？

本项目没有再单独要求配置：

```text
Bark
PushPlus
Telegram
企业微信
钉钉
飞书
```

而是直接调用青龙任务环境提供的：

```python
QLAPI.notify(title, content)
```

因此只需要先把青龙自己的通知配置好。

任务完成后，会自动使用青龙当前已经配置的通知渠道发送结果。

通知内容大致包括：

```text
小米钱包每日任务

执行时间：xxxx-xx-xx xx:xx:xx
账号数：1，成功：1，异常：0

账号：xiaomi_1
小米ID：xxxxxxxx
当前可兑换视频天数：xx.xx天
今日奖励记录：...
```

如果不想收到小米钱包通知，可以在青龙环境变量中添加：

```text
XIAOMI_WALLET_NOTIFY=0
```

恢复通知：

```text
XIAOMI_WALLET_NOTIFY=1
```

默认值就是：

```text
1
```

# 十、多账号使用教程

本项目支持多个小米账号。

默认第一次登录使用的别名是：

```text
xiaomi_1
```

## 添加第二个账号

进入：

```text
青龙面板
  ↓
环境变量
  ↓
新建变量
```

添加：

```text
名称：XIAOMI_WALLET_ALIAS
值：xiaomi_2
```

保存。

然后重新运行：

```text
小米钱包扫码登录
```

扫码登录第二个小米账号。

成功后配置中会同时存在：

```text
xiaomi_1
xiaomi_2
```

每日任务运行时会自动依次执行所有账号。

## 添加第三个账号

把环境变量改成：

```text
XIAOMI_WALLET_ALIAS=xiaomi_3
```

再次运行扫码登录任务即可。

## 刷新已有账号凭证

如果想重新登录 `xiaomi_2`，把环境变量设置为：

```text
XIAOMI_WALLET_ALIAS=xiaomi_2
```

然后重新运行扫码登录任务。

相同别名会更新原有账号，不会重复创建。

```text

```

# 十二、可选环境变量

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `XIAOMI_WALLET_ALIAS` | `xiaomi_1` | 扫码登录时使用的账号别名 |
| `XIAOMI_WALLET_CONFIG` | `/ql/data/config/xiaomi_qianbao_VIP/xiaomiconfig.json` | 自定义账号凭证保存位置 |
| `XIAOMI_WALLET_NOTIFY` | `1` | 是否使用青龙通知，`0` 为关闭 |
| `XIAOMI_WALLET_ACCOUNT_DELAY_MAX` | `15` | 多账号执行之间最大随机等待秒数 |

一般单账号用户不需要设置任何环境变量。

# 十七、常见问题

## 1. 提示“尚未添加账号”

例如：

```text
尚未添加账号，请先运行“小米钱包扫码登录”任务。
```

说明还没有成功保存账号。

解决：

```text
运行“小米钱包扫码登录”
↓
扫码
↓
手机确认
↓
看到“登录成功”
```

然后再执行每日任务。

---

## 2. 提示“长效凭证可能已失效”

例如：

```text
长效凭证可能已失效，请运行“小米钱包扫码登录”任务刷新凭证。
```

说明之前保存的 `passToken` 已经不能正常换取小米钱包临时 Cookie。

解决：

```text
小米钱包扫码登录
  ↓
重新运行
  ↓
重新扫码
```

相同账号别名会覆盖更新旧凭证。

---

## 3. 二维码无法识别

首先尝试：

- 浏览器缩小/放大日志页面
- 使用等宽字体显示
- 不要复制二维码文字后二次排版

如果仍然无法识别，日志中会同时输出二维码对应的登录 URL。

复制 URL 到浏览器打开，再用手机扫码即可。

---

## 4. 扫码后一直等待

扫码后通常还需要在手机上确认登录。

日志可能显示：

```text
已扫码，请在手机确认
```

此时检查手机是否出现确认页面。

如果二维码已经过期，重新运行扫码登录任务生成新的二维码。

---

## 5. 没有收到青龙通知

先确认青龙本身已经配置通知渠道。

本项目调用的是：

```python
QLAPI.notify(...)
```

如果日志显示：

```text
当前执行环境未提供 QLAPI.notify
```

说明当前运行方式没有注入青龙的 `QLAPI` 对象。

这种情况下任务结果仍然会完整输出到日志，只是无法通过青龙内置通知发送。

---

## 6. 每日任务显示“今日暂无新增奖励记录”

不一定代表脚本异常。

可能包括：

- 今日已经领取过
- 当前没有可执行任务
- 活动规则发生变化
- 小米接口返回的数据暂时没有新增记录

建议结合前面的任务执行日志判断。

---

## 7. 更新仓库后要重新扫码吗？

正常情况下不用。

因为登录信息默认保存在：

```text
/ql/data/config/xiaomi_qianbao_VIP/xiaomiconfig.json
```

而不是 Git 仓库目录中。

只有凭证本身失效时才需要重新扫码。

# 二十、最简使用流程

如果不想看完整教程，只需要记住下面几步：

```text
① 青龙 → 订阅管理

https://github.com/ZzzHe2333/xiaomi_qianbao_VIP.git

        ↓

② 手动运行一次订阅

        ↓

③ 定时任务 → 小米钱包扫码登录 → 运行

        ↓

④ 打开日志 → 扫二维码 → 手机确认

        ↓

⑤ 看到“登录成功”

        ↓

⑥ 手动运行一次“小米钱包每日任务”测试

        ↓

⑦ 正常后不用再管

        ↓

每天 08:37 自动执行 + 青龙通知
```
